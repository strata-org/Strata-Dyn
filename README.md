# StrataDyn

StrataDyn is a standalone Lean 4 package for the **Strata Dyn IR**, an intermediate representation shared by Strata language front ends such as the Python front end. It is built on [StrataDDM](https://github.com/strata-org/Strata-DDM), the Dialect Definition Mechanism of [Strata](https://github.com/strata-org/Strata).

## Building

From the repository root:

```bash
lake build
```
